# Leading with AI — Session 1: AI in Action

Training materials for **Session 1** of *Leading with AI*, a 4-session Generative AI & Prompt Engineering program for non-technical business leaders across HR, Finance, Supply Chain, Banking, and Sales & Marketing — delivered by **Dr. Avinash Kumar Singh** ([Robaita](https://www.robaita.com)).

## What's in this folder

| File | What it is |
|---|---|
| `genai_session1_deck.html` | The Session 1 slide deck — "AI in Action: From LLMs to Powerful Prompts." Self-contained, animated, click/arrow-key navigation. Open it directly in any browser, no install needed. |
| `Sales Data.csv` | ~186,000 real e-commerce order line items (2019, 9 US cities, 19 products) — used in the RTCCF and "From Data to Dashboard" exercises. |
| `HR Attrition Data.csv` | IBM's public HR Analytics employee attrition dataset (1,470 employees, 35 fields) — used in the HR dashboard exercise. |
| `Marketing Campaign Data.csv` | A public retail marketing-campaign dataset (2,240 customers, 5 past campaigns) — used in the Marketing dashboard exercise. |
| `Prompt Engineering.pdf` | Reference slides: prompt anatomy, RTCCF, and prompting technique examples. |
| `Prompt Engineering Examples.pdf` | Companion examples for role play, few-shot, chain-of-thought, RAG, and more. |
| `profile_pic_white.jpeg` | Presenter photo used in the deck's bio slide. |

## Opening the deck

`genai_session1_deck.html` is a single self-contained file — double-click it, or open it in any modern browser. No server or build step required.

- `→` / `←` or the on-screen buttons to move between slides
- **Contents** button opens a jump-to-section drawer
- Slides with a **Copy** button hold ready-to-use prompts — click to copy, then paste into ChatGPT or Claude
- Slides marked "Live demo" are meant to be run with the matching CSV uploaded live
